# FloraVision 🌿

A modern and visually immersive plant e-commerce landing page built using HTML, Tailwind CSS, and JavaScript.

FloraVision delivers a clean and premium shopping experience with smooth animations, responsive layouts, glassmorphism-inspired UI, and interactive sections designed for modern web aesthetics.

---

## ✨ Features

* Modern plant e-commerce landing page
* Premium glassmorphism-inspired UI
* Fully responsive design
* Smooth scrolling and reveal animations
* Interactive add-to-cart notifications
* Dynamic product rendering using JavaScript
* Lightweight and fast performance
* Clean and aesthetic user interface

---

## 🛠️ Tech Stack

* HTML5
* Tailwind CSS
* JavaScript (Vanilla JS)

---

## 📸 Sections Included

* Hero Section
* Trending Plants Showcase
* Top Selling Plants
* O2 Plants Collection
* Plant Categories
* Customer Reviews
* Footer & Newsletter Section
